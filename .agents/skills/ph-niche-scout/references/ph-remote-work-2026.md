# Filipino Remote-Work Resumes (2025–2026)

Guidance for resumes of Filipinos applying to **remote roles with overseas employers and clients**: direct hires on OnlineJobs.ph, LinkedIn remote roles, Upwork/agency contracts, and PH-based remote staffing firms. Use it alongside the niche files. Real job posts stored in SQL (`uv run resumeforge job list`) always outrank this file: when a stored post asks for something, follow the post.

> Sources: practitioner write-ups from remote-staffing firms and resume services (e.g. HireTalent.ph, VirtualStaff.ph, StylingCV, 2026), plus stored job posts. These are vendor blogs, not employer surveys. Treat them as signals and confirm against real posts.

## What overseas remote employers scan for first

1. **The exact role title from the post** in the headline. Resume-Matcher's title match and most ATS filters are literal.
2. **Proof of remote work**: "Remote", "Fully remote (US client)", the client or agency country, and how long the person worked without supervision.
3. **Time-zone overlap**, stated concretely: "Available 9am–5pm EST (night shift PH)" or "4-hour AEST overlap". Avoid a vague "flexible".
4. **Async and collaboration stack**, named in bullets and not only in skills: Slack, Google Workspace, Zoom/Google Meet, Loom, ClickUp/Asana/Trello/Notion, plus the role's core tools (GoHighLevel, HubSpot, Zapier, Make, n8n, Shopify, QuickBooks/Xero…).
5. **Measured outcomes for the client**: response times, tickets/week, leads booked, hours saved, revenue or show-rate lift. Prefer KPIs an overseas SMB owner cares about.
6. **Reliability signals**: tenure with the same client, a backup internet/power setup (UPS, fiber + LTE), and a quiet home office. Put these in one short line, for example in the summary or a "Remote Setup" note. Don't list them as a biodata dump.

## Conventions that differ from PH-local resumes

| PH-local resume | Remote/overseas resume |
|---|---|
| Expected salary in PHP | Usually omitted, or stated as a USD hourly/monthly rate only when the platform asks |
| Full address, birthday, civil status | City + "Philippines" only; never biodata |
| "Objective" paragraph | 2–3 line summary naming role, years, tools, and client type |
| Local employer names carry weight | Client **type** carries weight: "US dental group (40 staff)", "AU e-commerce brand" |
| Long seminar/training lists | Only certifications the post names or that prove the tool (HubSpot, GHL, Google, AWS…) |

## Platform notes

- **OnlineJobs.ph**: long-term direct hires (often full-time VA/ops/automation). Employers read the profile and resume closely, and the role title and tool keywords matter most.
- **Upwork**: project and contract work. The track record (job success, client reviews) carries the weight. A resume may cite "Top Rated" or job counts only if the persona's timeline supports it.
- **LinkedIn remote / agencies**: closest to a standard ATS pipeline, where keyword coverage and a clean parse matter most.

## Keyword integrity (anti-stuffing)

The ATS gate rewards covering a post's keywords. A gold-standard resume earns coverage **truthfully and naturally**:
- Add a missing keyword only if this persona would realistically have used it, and show it in a bullet or project, not only in the skills list.
- Never paste the post's sentences, repeat a keyword unnaturally, or list tools the career arc can't explain.
- If a keyword doesn't fit the persona, leave it missing. A lower but honest score beats a stuffed resume, and the auditor penalizes stuffing.
